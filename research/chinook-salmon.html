Project overview

Looking closely at cardiac tissue

I’m contributing to a project investigating Ichthyophonus infection in Yukon River Chinook salmon. My work involves developing skills in digital histology and image analysis with QuPath to examine parasites and changes in cardiac tissue.

This project page is a work-in-progress overview. Additional project details will be added when they are ready to share.
